# digests/: ваши дайджесты

Здесь лежат ваши конфиги (`<id>.yaml`) и журналы изменений (`<id>.changelog.md`). Папка не попадает в git
(кроме этого файла): портфель, интересы и адреса — личное. Создать: `digest init <id> --template morning`
или попросите агента: «хочу дайджест про …».

Для запусков в облаке (каждый раз чистая копия репозитория) конфиги вместе с памятью хранит
`digest state push/pull` в **приватном** репозитории — см. README, раздел «Память».
